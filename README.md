Самый лучший калькулятор расходов! Высокая скорость, понятный интерфейс, небольшой вес приложения!

Начать пользоваться очень легко! Откройте проект в любом редакторе кода и запустите программу. 

На выбор вам будет доступно 5 функции:
1. Добавить расход. Сохраняет в список расходов трату с определенными параметрами.
2. Показать список расходов. Выводит список всех добавленных ранее расходов. Пока представлены в виде словарей. Поддержите проект, чтобы улучшить визуальное представление)
3. Показать общую сумму. Выводит общую сумму трат.
4. Показать расходы по категории. Выводит список только с тратами по выбранной категории.
5. Выйти. Завершает выполнение программы.
